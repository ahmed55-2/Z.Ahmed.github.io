Zaheer Ahmed Portfolio Website

Contents
- index.html: main portfolio page
- styles.css: all visual styling
- script.js: theme switcher, current year and copy-email button
- assets/profile.png: professional profile image

How to use
1. Keep the folder structure unchanged.
2. Open index.html in any modern browser to preview the site.
3. Edit text in index.html to update your profile and experience.
4. Edit styles.css to change colours, spacing or layout.
5. Replace assets/profile.png with another image if required.

Publishing
You can upload these files to GitHub Pages, Netlify, Vercel or another static web host.
This is a static site and does not contain a backend/admin login. All source files are included so you have full editing control.
